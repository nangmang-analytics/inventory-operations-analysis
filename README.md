# Inventory Operations Analysis

**Excel & PostgreSQL | Data Analytics Portfolio Project**

## Project Overview
Analyzed 159 inventory and order records across three warehouses in Dallas, Tulsa, and Oklahoma City from January through June 2026.

The project focuses on inventory shortages, supplier delivery performance, inventory value, and order trends.

## Tools Used
- Microsoft Excel: Data cleaning, PivotTables, charts, and reporting
- PostgreSQL: SQL queries, aggregations, and data validation

## Key Findings
- Identified 45 records (28.3%) below their reorder points.
- Found a 639-unit shortage for Copper Wire Spool.
- Analyzed $846,643.45 in recorded inventory value.
- Validated delivery analysis using 146 complete records after identifying 13 missing late-day values.
